#+TITLE: Dual-encoder shoeprint retrieval

Retrieval of reference shoeprints from crime scene shoemarks. Separate
ResNet-50 encoders embed the two domains into a shared space, trained with a
triplet margin loss on real impression pairs and on synthetic shoemarks
produced by a generator.

* Installation

Choose the build of torch that matches the card:

#+begin_src sh
uv sync --extra cuda
uv sync --extra rocm
#+end_src

Because torch comes from an extra, pass the same one when running, otherwise
=uv run= resolves an environment without it:

#+begin_src sh
uv run --extra cuda python src/training.py final_combined.toml
uv run --no-sync python src/training.py final_combined.toml
#+end_src

The examples below leave the extra out for brevity; add the one installed.

* Configuration

Options resolve as defaults, then the configuration file, then command-line
arguments. All options are declared in =src/siamese/config.py=. An unknown key
in the configuration file or on the command line is an error. Overrides name an
option by its dotted path and accept TOML literals.

#+begin_src sh
uv run python src/training.py
uv run python src/training.py final_combined.toml
uv run python src/training.py --training.epochs 7500 --curriculum.enabled true
#+end_src

* Synthetic shoemarks

Synthetic marks are generated ahead of training by =generate_pool.py= in the
UNSB repository, then streamed from disk. The pool directory is set by
=data.streaming.synthetic_shoemark_data_dir=. When the difficulty curriculum is
enabled, sibling directories named =<pool>_d<level>= supply marks at each
difficulty level.

* Evaluation

#+begin_src sh
uv run python src/evaluation.py checkpoints/<run> --dataset test -p 5
uv run python src/failure_analysis.py checkpoints/<run>/siamese_<epoch>.tar --dataset wvu
#+end_src

=evaluation.py= scores every checkpoint in a directory, reporting the
proportion of query shoemarks whose correct shoeprint ranks within the top p
percent of the gallery. =failure_analysis.py= collects the queries that fall
outside that threshold, writing each with its correct and incorrectly matched
shoeprints for inspection.
